# Catalog import

`intake-to-yaml.ts` converts the retained intake CSV shape into canonical launcher entry YAML. It is an operational import aid, not part of application startup.

Run:

```sh
npm run catalog-import -- tools/catalog-import/catalog-intake.example.csv > /tmp/imported.yaml
npm run validate-config -- /tmp/imported.yaml
```

Review generated entries before merging them into deployment configuration. Security policy is never generated by this tool.
