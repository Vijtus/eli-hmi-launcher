# TESTZ deployment material

This directory is deployment data and operational evidence for TESTZ. It is intentionally outside the generic launcher source/config architecture and can be extracted to a deployment repository later without reorganizing the application again.

- `launcher.yaml`: TESTZ local trust/bootstrap configuration.
- `config-repo/`: TESTZ host/zone data used as deployment evidence/example material.
- `panels/`: TESTZ panel artifacts.
- `field-reports/`: field observations, not product documentation.
- `evidence-screenshots/`: historical/manual UI and acceptance evidence; these are not visual-regression fixtures.
- `archive/`: historical status/blocker documents retained for deployment traceability only.

Current product behavior is documented in the repository root and `docs/`, not here.
